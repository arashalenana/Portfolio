About

About Me

Software developer building practical, business-focused web solutions — from responsive front ends to the databases and server logic behind them.

I'm a software developer focused on building digital solutions that work well and solve real problems. My work spans business websites, web applications and database-driven systems, using HTML, CSS, JavaScript, PHP, Python and MySQL as my core toolkit.

I approach every project the same way: understand what the business or user actually needs, then build a clean, functional interface backed by solid server-side logic and a well-structured database. I write code that's meant to be maintained, not just shipped.

Beyond the core stack, I work with Django for backend development and use Git, GitHub, VS Code and XAMPP as part of a standard development workflow, deploying projects through Netlify and Azure.
